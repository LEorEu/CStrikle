# 归档

**这里的文件都不描述现状。** 它们负责回答「这条规则当初为什么这么定」，
不回答「今天是什么样」。上一级目录只放当前状态，那四份才是准的：
[README](../README.md) / [开发主线](../开发主线.md) /
[比赛引擎_v0.3](../比赛引擎_v0.3.md) / [数据快照](../数据快照.md) /
[卡牌与落地记录](../卡牌与落地记录.md)。

和现状冲突时一律以上一级为准。**归档里的结论不改写**——把当时的判断改成
今天的答案，等于把「我们曾经这么想过、后来发现不对」这条信息删掉，而那恰恰
是这些文件唯一还有的用处。同理，里面写的 `scripts/proto_*.py` 这类旧路径也
保持原样，换算表在 [../../README.md](../../README.md) 里。
