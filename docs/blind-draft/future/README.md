# 未来设计

**这里的东西都没有接进流程，也不是待办。** 放这儿是因为它们已经想清楚到
「哪天要做，不用从头再想一遍」的程度——不是因为快要做了。

要判断下一步做什么，只看 [开发主线.md](../开发主线.md)。

| 文件 | 是什么 | 为什么现在不做 |
|---|---|---|
| [回合引擎_v0.1.md](回合引擎_v0.1.md) | 把一张图的黑箱结果展开成回合过程：实时比分、Round Log、Kill Feed、K/D/A、ADR、KAST、Match Rating。依赖 Match Engine v0.3 | 它是**表现层**，不改任何胜负。当前闭环还没被真人试玩验证过，先把「玩家能不能感到刚才选的五个人导致了后来发生的事」跑通，再考虑把一张图摊开成 24 个回合 |

一条边界，写在这里免得以后有人跨过去：**回合引擎不许反过来决定胜负。**
一张图谁赢由 `blinddraft.engine` 算完，回合过程只负责把那个结果讲成一段可看的
故事。反过来做的话，Player Story 的归因（每一分变化拆到状态/压力/软顶）就再也
对不上账了。
