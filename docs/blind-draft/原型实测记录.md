# Blind Draft 原型:实测记录与结论

**起于 2026-08-18,记到 v3.4。** 玩法蓝图见
`玩法蓝图_v0.2.md`,落地记录见 `卡牌与落地记录.md`。
这一份是**可玩原型 + 真人试玩**的记录:每一条结论后面都跟着产生它的那组数字,
以及复算的方法。

一句话:选手卡体系已经做完了,但**消费这些卡的那一层还不存在**,所以先做了一个
不带 UI、不带比赛模拟的原型,让作者本人上手,用「哪一轮真的犹豫了」当信号,
判断这套选人到底有没有决策。

**这份文档是按时间顺序写的,二、三、五节是 v1/v2 当时的状态和结论,不是现状。**
现状看第六、七、八节——v2 里的零和整形、星级卡面、Quality Offset 都已经撤掉
(原因在六·2),七·2 收紧的 6 轮 1 跳也在 v3.4 撤回了(原因在八·1)。当前形态
一句话概括:**卡是固定的,市场会给他报错价,卡面只给球探区间;选人时你看得见
可以去追哪几种阵容,散场时每一张牌都会翻开。**

---

## 一、为什么先做原型

设计讨论到「线索系统 / Board Generator / 队伍层属性」三选一时卡住了,卡点不是
技术,是**吃不准玩家想要什么**。原型的作用是把「需要猜对」的部分挪走:

- 受众不是「大部分人」,是已经在玩猜选手模式的那批 CS 观众——他们为「我懂这段
  历史」买单,不为策略深度买单。奖励懂球的机制风险低,要求策略素养的机制风险高。
- 按**猜错的代价**排序,而不是按好不好:Reveal / 图鉴(零风险)→ 默契 / run 修正
  (一个系数就能关)→ AI 抢牌 / 淘汰制结算(改流程改数值观,反悔要重做)。
- 作者自评接近新手,**这在这个项目里是资产**:他就是目标用户样本。
- 判据设得很硬:**规则全透明,身份仍然盲。如果在能看见全部计分规则的情况下这个
  Draft 都不好玩,那加上盲抽和模拟只会更糟**——后者只减少信息,不增加决策。

## 二、原型 v1 与五局实测

`scripts/proto_draft.py` 第一版:预算 $15、5 轮、每轮 $5..$1 各一张选一张,
卡面给国籍 / 年龄 / Major 次数,身份赛后揭晓。算分刻意做成非加法的(火力由
最高与次高主导、领导只看 IGL、默契来自真实同队经历),赛后穷举同一批板面能组出的
全部阵容给名次——**名次分布挤不挤,就是「选什么都一样」的判据**。

### 2.1 五局的成绩

| 局 | 认出人了吗 | 名次 | 你 vs 瞎点 | 最优 vs 瞎点 |
|---|---|---|---|---|
| s1mple 局 | 认出 | **1090 / 1753(62%)** | **−1.4** | +14.3 |
| shox 局 | 认出三个 | 812(46%) | +1.0 | +16.8 |
| Twistzz 局 | 认出(但选错) | 576(33%) | +3.1 | +14.4 |
| 「一个都不认识」局 | 否 | 144(8%) | +7.9 | +16.5 |
| dupreeh 局 | 部分 | 72(4%) | +9.0 | +17.2 |

**认出人的两局是打得最差的两局,其中一局输给随机瞎点。** 但重放之后,原因和
直觉相反。

### 2.2 结论一:买贵卡从来不是错误,错的是买完之后不敢花钱

```
你买的卡按价位看,平均后悔值(其余四人不动、只换这一张能多拿多少)
  $5  0.0     ← 买 s1mple / dupreeh / shox 三次,一次都没选错
  $4  3.7
  $3  3.8     ← 分全丢在这里
  $2  2.0
  $1  1.8

同一板面里买某一档的卡,平均把总分推高/拉低多少
  $5 +2.88   $4 +1.66   $3 −0.61   $2 −0.78   $1 −1.23

最优 20 套阵容的价格组合 top5: 55311 / 54321 / 55221 / 54411 / 55211
```

s1mple 那局的真相:买完 $5 之后连买 $3/$2/$2/$1,**最后还剩 $2 没花出去**,
而板面上还躺着 fer($5)和 kennyS($4)。shox 那局的价格组合 `54411` 本身就在
最优模式里,丢分在「五个人四个步枪 + 一个 IGL,没有 AWP,硬扣 4 分」。

**真正的决策一直是「钱怎么劈」,而界面上完全没有这件事的提示。**

### 2.3 结论二:卡面线索是有害的,不是弱

```
同一档位内的 overall 均值
  G5   ≤24岁 85.4   ≥30岁 85.3      Major≥6 85.4   Major≤2  —
  G4   ≤24岁 75.5   ≥30岁 75.9      Major≥6 75.7   Major≤2  —
  G3   ≤24岁 63.5   ≥30岁 64.0      Major≥6 64.4   Major≤2 63.0
  G2   ≤24岁 53.1   ≥30岁 53.6      Major≥6 53.8   Major≤2  —
  G1   ≤24岁 43.9   ≥30岁 43.6      Major≥6  —     Major≤2 43.7
```

年龄和 Major 次数在同价位内的信息量是噪声级(差 0.1~0.6 分)。人一定会拿屏幕上
有的东西建立直觉,所以玩家必然产生「年轻 + 经验多 = 捡漏」的感觉,然后必然被打脸。
**这不是线索太弱,是线索有害:它让玩家在一个和答案无关的维度上认真推理。**

### 2.4 结论三:同价位的卡是克隆人,「捡漏」在数据结构上不可能

生成器是「模板 + 小修正 + 抖动」,G1 步枪一律 52/20/20/48±4。所以 Reveal 里
显示的 `+1.6 捡漏` 全是抖动噪声。**在同价位内根本不存在「更好的那张」。**
这一条比线索问题更深一层,是 v2 的主要改动动机。

### 2.5 玩家自己提出的三件事(全部证实)

- **「两个 IGL 还比之前分高」** —— 漏洞。领导力算「最强 IGL ×0.7 + 其余四人
  均值 ×0.3」,而 IGL 卡的 leadership 是 53~96、步枪只有 17~30,多塞指挥能把
  「其余四人」那项顶上去。现实里两个指挥是抢话。
- **「一轮全是步枪没有 AWP 难受」** —— 发牌完全随机,一轮可以一个 AWP 都没有,
  而没 AWP 要扣 4 分,等于凭空吃一个躲不掉的惩罚。
- **「最后一轮想跳过」** —— 整份日志里最有价值的信号。省下来的钱没有任何用途,
  所以跳过在数值上永远是错的,可玩家还是想跳:**他要的那个决策(现在买 vs 留着)
  游戏根本没提供。**

## 三、原型 v2 的改动

> **以下是 v2 当时的状态,不是现状。** 3.1 的零和整形和 3.2 的星级卡面都已在
> v3.2 撤掉(原因见六·2:整形让年龄成了火力的主要驱动,星级则是同价位分位,
> 撤掉整形之后不再需要)。3.3~3.5 那三条(跳过换牌、两个修复、出场权重)保留至今。

### 3.1 同价位做出形状差异(零和整形)

同价位**不拉开强弱、只拉开形状**,加权 overall 逐张守恒:

```
形状取自真实履历而不是随机撒点:
  年轻            → 火力高 / 稳定低(打得凶但飘)
  Major 与冠军多  → 经验高 / 火力让一点(老兵)
整完给全卡加一个常数把加权 overall 拉回原值
(位置权重和为 1,四维同加 c 等于 overall 加 c)

同样 $2、同样的 overall:
  火力 ★★★★☆  稳定 低    ← 年轻的玻璃大炮
  火力 ★★☆☆☆  稳定 高    ← 老油条,经验高
```

**价格阶梯完全不动**(`卡牌与落地记录.md` 三·1 那套定价保住),捡漏第一次
成为可能,而且是**相对自己阵容才成立**的捡漏。整形只活在原型里,
**没有回写 `gen_draft_cards.py`**,等验证完再决定。

### 3.2 卡面换成球探报告

去掉年龄和 Major 次数,改成 `火力 ★★★★☆`(同价位内的分位)+ 轮换的第二项
(稳定 / 经验 / 领导,三选一,**留一项不告诉玩家**)。国籍保留——它是唯一有机制
意义的身份线索(默契)。

### 3.3 跳过 = 换一批牌

7 轮机会填 5 个位置(自带 2 次跳过),钱允许留着。赛后给**留钱曲线**:

```
同一批牌里,花掉 N 块的所有阵容的平均分
  $15 → 61.9    $14 → 60.2    $13 → 58.1    $12 → 56.4 …
每留 1 块平均亏 1.7 分,但最高分掉得更快(73.1 → 68.0)
```

**留钱主要砍的是上限,不是均值。**

### 3.4 两个修复 + 自动复盘

- 第二个 IGL 不再加领导力,改成默契项「N 个指挥抢话 −3」。
- 发牌保证每批至少有一个 AWP 和一个 IGL(**这条后来被证明是新的坑,见五·2**)。
- 赛后自动给逐轮后悔值,不再需要事后重放才知道亏在哪。

### 3.5 出场权重:压掉不认识的老哥

全库 52% 没队伍、44% 在 30 岁以上,板面长期被「十年前的无名老哥」占满。
**只改出场率,不改任何卡的数值,人都还在库里。** 两条折扣相乘:

```
FREE_AGENT_WEIGHT = {5:1.0, 4:0.8, 3:0.35, 2:0.25, 1:0.20}   没队伍
VETERAN_WEIGHT    = {5:1.0, 4:0.9, 3:0.50, 2:0.40, 1:0.35}   ≥30 岁
例外:≤24 岁的自由身折扣只打一半 —— 年轻没队的可能正是没被认出来的厉害人
```

$5/$4 不打折是刻意的:那一档没队的是 f0rest、olofmeister、dupreeh,**恰恰最好认**。
实现用 Efraimidis–Spirakis 带权无放回抽样(`key = u^(1/w)`,升序排好从尾部取)。

实测板面构成(400 局 × 7 轮):

```
              没队            ≥30 岁
$5    41% →  34%        62% → 62%     传奇原样保留
$4    31% →  28%        40% → 37%
$3    52% →  25%        43% → 22%
$2    49% →  17%        44% → 17%
$1    57% →  21%        42% → 12%     其中 ≤24 岁自由身仍占 8.7%
```

> 踩过的坑:`Dealer.board()` 的重发路径原本用均匀洗牌,把权重整个冲掉,
> 改之前 G1 的「没队」只从 57% 降到 54%。**带权抽样的每一处重洗都必须带权。**

## 五、v2 三局实测:问题换了个位置,但还在

三局的名次是 12% / 39% / 10%,玩家的评价仍然是「不够好玩」,具体是
**「后面位置上容易选崩」** 和 **「认出来直接买,结果也就那么回事」**。
用 Python 复刻 mulberry32 重放了这三局(分数逐局对得上)。

### 5.1 后期的选择塌缩成两张牌,而且必然是不需要的位置

```
最后两轮里可买的牌:19 张,其中「位置我已经有了」19 张 —— 100%
```

每批牌固定 $5..$1 各一张,钱一少,买得起的就只剩 1–3 张,位置全靠天。
典型:ZywOo 那局 R6 剩 $2、还差 1 人,买得起的只有 `$2 IGL` 和 `$1 AWPER`,
而 AWP 和 IGL 都齐了。

**但那一轮的实际后悔值是 0.0**,draken 甚至就在最优阵容里。
**游戏让玩家为一个不影响结果的选择纠结了半天——假决策比选错更伤体验。**

### 5.2 「保证每批有 AWP 和 IGL」帮了倒忙

```
每批牌里步枪的张数: 0 张 1%  ·  1 张 12%  ·  2 张 39%  ·  3 张 47%
```

**永远不会超过 3 张。** 卡池 62% 是步枪,但强制每批必有 AWP 和 IGL,
五个格子里只剩 3 个能放步枪。越到后面越缺步枪,越买不到。
这是 v2 修 bug 修出来的新洞。

### 5.3 玩家打出满分局,游戏却没告诉他

seed 603937016 那局**五张牌逐轮后悔全是 +0.0**——在他参与的五批牌里每一张都
选对了,12% 的名次差距全部来自跳过的判断。游戏只甩出一个 `4530/36813`,
**没有区分「选牌很准」和「路线判断差」,所以赢了也没感觉。**

### 5.4 认人依然等于正确答案

donk +0.0、kennyS +0.0、ZywOo +0.7——认出来直接买,数据说买对了。
**只要计分是「凑最高总分」,认出名人就等于知道答案。**
唯一反例是连买两张 $5 狙那局(后悔 +3.4 / +3.8):**认出的人最多,名次最差。**

### 5.5 「适配」存在,但默契基本没醒过来

```
同一批候选卡换一套「已有的四个人」,价值排序相关性 +0.536
  (1.0 = 阵容对选择毫无影响;完全一致的板面占 16%)
随机五人阵容里的真实队友对数:平均 0.14 对,一对都没有的占 87%
手上两个人时,新一批牌里出现他们真实队友的概率:34%
三局的默契分:−0.5 / +1.5 / 0
```

**适配是真实存在的决策(0.536 不是 1.0),但它几乎全是位置适配,
而位置适配恰恰是玩家后期最买不到的东西。** 默契这条本该让「认人」变成
「只有我知道的信息」的通道,目前处于休眠。

## 六、v3:把问题从「这是谁」换成「这值不值这个价」

取向由作者定:**「我抄到过多少底」比「我认识多少人」有意思得多;先能玩进去,
才谈得上想认识这些人。** 一切为有趣服务。

v3 出过一版走偏的,评审之后回调成 v3.2。**下面先分清两类东西**——文档此前把它们
混着写,是「越做越不像一开始聊的游戏」那种感觉的主要来源:

| | 正式机制(要进最终游戏) | 原型测试桩(只为验证,不是玩法) |
|---|---|---|
| 卡 | 固定四维 + 固定档位,生涯代表版本 | — |
| 价格 | 市场这一局给他报的价,会错 | — |
| 卡面 | 标价 / 位置 / 球探区间 / 国籍 / 一条履历线索 | — |
| 余钱 | 买 Buff,走另一条构筑路线 | 暂折算成火力,只为回答「省钱会不会变成真决策」 |
| 结算 | 打完比赛看结果 | 穷举同批牌的全部阵容给名次 |

### 6.1 市场错价:先抽到人,再为他报价

v1/v2 的 $5 只是 G5 的别名——价格先播报了档位,所以认出名人就等于知道答案。
这是「认人 = 答案」的上游,比「目标函数是加法的」更根本。

**顺序很重要,而且不是概念洁癖。** 正确的是:抽到这个人 -> 读他自己固定的档位 ->
市场这一局给他报个价(在他档位上下一档之间浮动)。反过来做(先定价格、再从价格
附近生成一个档位的人)实测会让 34 个 G5 被反复回收:

```
        卡池占比   板面占比(先定价格)   板面占比(先抽人)
G5        5.2%         21.3%  x4.1        11.1%  x2.1
G4        5.4%         17.3%  x3.2        15.1%  x2.8
G1       47.7%         25.4%  x0.5        25.7%  x0.5
```

先抽人之后剩下的放大来自一个**显式的**「进货权重」`GRADE_WEIGHT`——卡池 47.7%
是 G1,照原样抽的话板面全是便宜货、$15 根本花不掉。它只决定谁被摆上货架,
不碰任何人的档位和四维,而且是一个能单独调的旋钮。

结果:每批牌大约有一张的价格是错的(20% 的牌档位高于标价),而标价与 overall
中位数仍然单调($1 44.5 / $2 53.2 / $3 62.9 / $4 75.2 / $5 85.1)——**价格信号还在,
但会错**。抄底说的是真话:一个 G3 这局卖 $1,他真的就是 G3。

### 6.2 卡面是球探报告,不是完整属性

先说一个撤掉的东西。v3 第一版在这里加了两层加工,都撤了:

- **Quality Offset**(按 HLTV top100 队伍排名 / 近年是否还在打 / Major 前八 /
  生涯跨度推同档实力差)。撤,因为「近年是否还在打」当加分**直接违反 §14
  「一律按生涯代表版本评价」**——一个退役传奇不该因为退役掉数值;而队伍排名是
  队伍指标,好选手在烂队、角色球员在强队都很常见。这等于在没有 Rating 的情况下
  用代理指标重造一个隐藏 Rating,正是这个项目当初主动放弃的那条路。
- **零和整形**(同档 overall 守恒,只换形状)。撤,因为 overall 只是内部估值工具,
  不是守恒量——一个又强又稳又有经验的人本来就该三项都高,没道理让经验 +8 去还
  -4 的火力。更糟的是它让**年龄成了火力的主要驱动**:donk 和 dev1ce 光生日就差
  6 点火力,m0NESY 因此排到 ZywOo 前面。和 `41df824` 骂过的「一个生日值 18 点
  火力」是同一个毛病,换了个位置又犯一次。

**现在卡面上的四维就是卡库里的四维,原型不做任何加工。** 但这样一来直接给数字
就不行了:卡库是「按档位套模板 + 小修正」生成的,相邻档几乎不重叠——

```
G1 步枪 48~58   G2 56~65   G3 66~76   G4 80~85   G5 90~96
```

写「火力 70」等于直接说「这是 G3」,而档位正是市场错价要藏的东西,抄底就退化成
一道查表算术。所以卡面改成**球探区间**:那一维给一个区间,真值一定在里面,
**但不一定在中间,宽度也不固定**,签下来(Reveal)才看到精确数字。

参数是扫出来的,而且扫出了一个反直觉的结论:**决定「能推断多准」的不是区间宽度,
是真值允许落在区间里的位置范围**(可推断窗口 = 位置跨度 x 宽度)。

```
宽 8-14 · 位置 30-70%   一个区间平均对应 1.12 档   只对应 1 档 88%   窗口 ~4 点
宽 8-14 · 位置  5-95%                    1.37 档              63%   ~10 点
宽 12-18 · 位置 5-95%                    1.61 档              39%   ~13 点  <- 采用
```

把真值锁在区间中段(30~70%)看着更「可信」,可窗口只有 ~4 点,比档位带(约 10 点)
还窄,88% 的区间照样只对应一个档位——等于白改。真值必须可能贴边,相邻档才在球探
报告这一层真正重叠:

```
「火力 60-74」 -> G2 50% / G3 50%
「火力 70-85」 -> G3 72% / G4 28%
```

**允许玩家算概率,不允许玩家算出答案。** 代价是球探偶尔很不准——但那正好让
Reveal 里的「超出预期(卡在上沿)/ 贴着下沿」有了意义。区间每次发牌重摇、不跟着卡
走,否则区间本身会变成这个人的指纹,又能查表。

卡面完整三层:**标价** / **位置 + 球探区间**(按位置加权挑一维:步枪偏火力稳定,
指挥偏领导经验;非 IGL 的 leadership 是常数模板,展示了等于死线索,不发) /
**国籍 + 一条履历线索**(俱乐部、Major 次数、年龄三选一)。

### 6.3 发牌:按剩余预算 + 按需供给

标价全部落在 `max(1, min(5, 余额 - 剩余席位 + 1))` 以内,后期不再塌缩成两张
(v2 的病)。缺的位置权重 x2.5,只在最后一两个位置才硬保底——撤掉了 v2「每批必有
AWP+IGL」那条,它把步枪封在 5 选 3,而卡池 62% 是步枪。

真实队友权重 x2:实测把「板面出现已有队员的真队友」从 39% 抬到 57%。
**没有采用硬塞**——那会变成「发牌员帮你做 Build」,而 x2 足够让人碰上又不保证。

### 6.4 Rogue Points(测试桩)

剩下的钱记作 Rogue Points。正式设计里它买 Buff、走另一条构筑路线;Buff 还没做,
所以原型暂按「1 点 = 全队火力 +1.5,最多算 4 点」折算进分数,**只为回答「如果余钱
有价值,省钱会不会变成真决策」**。UI 和文档都明写这是测试桩。

兑换率扫过:R=1.5 时最优打法平均留 $1.5、比「花满」高 1.26 分(R=0 时也有 +0.80,
因为板面不总能正好花完 $15),再高就变成囤钱恒对。上限 4 点借用「Buff 位有限」
这个正式设计里就有的理由,挡住「全买 $1 囤一堆钱」的退化解——不设的话,一局留 $9
就能换全队火力 +27。

### 6.5 结算分维度

选牌准度(逐轮后悔合计)/ 预算管理(同样花这些钱最高能到多少)/ 阵容契合 /
最大抄底,外加「你错过的最大抄底」。v2 打出过满分局却只看到一个 `4530/36813`,
赢了也没感觉。

### 6.6 还没有验证的

- 抄到底的那一下爽不爽,球探区间读起来是不是像 FM 的球探报告。
- 老玩家的知识有没有从「答案」降级成「边际优势」:认出 ZywOo 之后,问题是不是
  真的变成了「他怎么只要 $3,我买不买」。
- Reveal 的情绪来源换了:从「原来是他」变成「我三块钱买到了 ZywOo」。图鉴那一层
  的口径要跟着从「我认识多少人」改成「我抄到过多少底」。

### 更上层的、还没有答案的问题

- **认人 = 答案** 这件事,只要目标函数是「凑最高总分」就无解。真正的出口是让
  正确答案依赖识别**给不了**的信息(阵容适配、默契、本局条件),而不是继续调线索。
- **加法目标是空的**:五席固定 + 每块钱边际收益近似常数 ⇒ 任何预算分配总分接近。
  `sim_draft.py` 当年「10 种价格组合都活得下去」不是平衡好的证据,是没有决策的
  证据。原型靠明星主导 + 默契把它掰成非加法的,但强度还不够。
- **比赛模拟层仍然不存在**,而它决定了上面这些设计是不是白做。v3 把选人这一层
  做到了能玩,但四维(尤其形状:年轻人火力高稳定低 vs 老兵经验高稳定高)仍然没有
  兑现场景。下一个里程碑应该是**极简 Run**:选完五个人跑三关(BO1 / BO3 / 高压
  淘汰局),让稳定、经验、领导真正改变结果。等这三关能让人产生「早知道我刚才选
  另一个」,再往 Major、Buff、BP 扩。

## 七、v3.3:把顺手感拿掉,给这五个人一个名字

v3.2 三局实测(附录 A)的共同点很整齐:钱几乎花满、每局都抄到底、都能凑出像样
阵容、名次都很好(557/44519、191/49372、49/59577)。作者的判断是「好很多了,
但还差一点味道」。

这句话本身就是结论:**缺的已经不是决策质量。** 第三局 49/59577 已经贴着这批牌的
数学最优,把名次从 49 推到 500 不会更好玩。现在的手感是「大概看看球探信息,
看到便宜货就买,缺什么位置补什么,最后通常能组出一支挺强的队」——顺,
但没有「这轮我到底怎么办」。

所以这一版只动三个小旋钮,**不碰球探区间、不碰卡库**(球探那一层已经达到目的,
冻结)。

### 7.1 抄底从「每局固定发放」改回「有时候有」

原来的 `MARKET_ROLL` 是对称的 25/50/25。

真正该量的**不是**「看过的 30 张牌里有没有抄底」——那个数永远接近 100%,
一局要看 30 张牌,再低的概率也撞得上;该量的是**到手的 5 张里有几张**:

```
                         0 张   1 张   2 张+
25 / 50 / 25(原)        13%    29%    58%
12 / 70 / 18(现)        38%    41%    21%
```

58% 的局里抄到两张以上,抄底就不是故事,是系统稳定发放的奖励。
**而且作者那三局其实每局都抄到了 3 张**——Reveal 只报「最大抄底 +1 档」,
所以他自己都没看见。这条顺带说明结算面板报错了重点:抄了几张比抄得多深更有信息。

不对称是有意的:**好货不常打折,坑货倒是不少。** 12/70/18 落到板面上是
**抄底 9.2% / 高估 14.2%**——两边都比权重低,因为报价还要被「你还买得起多贵」
截断一次(越穷,买得起的越只剩报价偏低的那些,所以穷的时候板面反而更像打折区)。

顺带修了一个埋着的雷:`MARKET_ROLL` 的注释把 delta 的符号写反了(注释写
「档位 − 标价」,代码算的是 `price = 档位 + delta`)。25/50/25 对称,所以这个错
从来没暴露过;一旦改成不对称,照着注释写就会把抄底和坑货**调反**。

### 7.2 7 轮 2 跳 → 6 轮 1 跳(**已在 v3.4 撤回,见八·1**)

两次跳过是 v2 的拐杖:当时后期买不起牌、缺的位置又不发,需要额外两轮救命。
v3 已经按剩余预算发牌 + 缺位提权 + 最后硬保底,病治好了,拐杖还留着。
三局分别跳了第 (4,5)、(1,4)、(1,5) 轮,全都在用跳过淘牌——这很可能就是「顺」的
主要来源。

改回 6 轮之后,唯一那次跳过重新是资源:第一批很普通,现在就用掉,
还是留着赌第六批不会更差?

### 7.3 阵容标签:给这五个人一个「这是支什么队」的答案

Reveal 现在只有分数和一串加减分流水账(「同国籍 Denmark ×2 +1.5」)。可第一局
dev1ce + s1mple + cadiaN 摆在一起,一个 CS 观众的第一反应不是「74.43 分」,
是「你这队准备怎么打」。

所以加一层**只命名、不算分**的标签。不算分是刻意的:位置冲突、同国、同代、
真队友的加减分早就在 `chemistry()` 里算过,再给一次就是重复计分,也等于又塞进来
一个没验证过的旋钮。

分两类,这个区分才是它有用的地方:

| | 判定用什么 | 玩的时候 |
|---|---|---|
| **aim** | 只用卡面看得见的(位置、国籍、标价) | **选人时就能朝它走**:手里已经两个 AWP,第三个买不买 |
| **blind** | 要身份揭晓才知道 | 撞上的 |

- aim:`RIFLE ONLY` / `DOUBLE AWP` / `AWP OVERLOAD` / `NO CALLER` /
  `TWO CALLERS` / `<国家> CORE` / `MONEYBALL` / `GALACTICOS`
- blind:`<队名> CORE` / `REUNION` / `INTERNATIONAL MIX` / `MAJOR WINNERS` /
  `SAME GENERATION` / `GENERATION GAP` / `BARGAIN BIN` / `FLEECED`

阈值是照着出现率调出来的——**一个每局都亮的标签不是身份,是噪音**:

- `INTERNATIONAL MIX` 按「五个国家」判,57% 的局都会亮;改成「五个国家
  **且**五个人互相没打过」才真的是「拼凑」。
- `MONEYBALL` 从「最贵 ≤$3」收到 `≤$2`——$15 招 5 个人,均价本来就是 $3。
- `GENERATION GAP` 从 12 岁提到 14 岁(卡库横跨 2013~2025,12 岁差太常见)。

调完之后每局 1~3 个标签占 75%,一个不亮的只有 3%。

队名要挑**一起打过最多届 Major 的那一支**,不是最多人待过的那一支:后者会把
dev1ce + Xyp9x 报成 dignitas(同队 1 届)而不是 astralis(同队 8 届)。网页版为此
在 `pairs` 里多存了一个「在被点名的那支队一起打了几届」——`chemistry()` 判
`>=5 届` 用的是两人同队**总**届数(15 届),两个数不是一回事。

三局历史阵容跑出来是这样:

```
dev1ce/FL4MUS/esenthial/cadiaN/s1mple   DOUBLE AWP · MAJOR WINNERS · BARGAIN BIN
JT/mezii/Jimpphat/dev1ce/Xyp9x          REUNION(astralis 同队 8 届)· MAJOR WINNERS · BARGAIN BIN
YEKINDAR/Aleksib/NAF/esenthial/kennyS   REUNION(liquid 同队 3 届)· BARGAIN BIN
```

(三局的 `BARGAIN BIN` 都是旧的 25/50/25 打出来的;新口径下它只有 21% 的局会亮。)

命令行版和网页版逐条对齐,网页版的判定在 node 里单独跑过对拍。

### 7.4 故意没动的

- `NEED_BOOST = 2.5` 保持不变。评审建议降到 1.5~2.0,但一次只动几个变量,
  否则下一轮又分不清是谁起的效——先看这三条改完还顺不顺。
- Rogue Points 仍然是测试桩。三局分别花了 14/15/15:现在省钱只换来一点总分,
  换不来一条**不同的路线**,那要等 Buff。

### 7.5 下一步

这三条都只是**把顺手感拿掉**,只有阵容标签算加了新东西,而且它加的是叙述不是玩法。
真正缺的仍然是**选完之后发生什么**——极简 Run(BO1 / BO3 / 高压淘汰局),
见下面「更上层的、还没有答案的问题」。

## 八、v3.4:让玩家能追一支自己想要的队

这一版的输入不是「哪里不平衡」,是玩家玩完第二局说的一句话:

> 「其实一开始是想组一个独联体的青春风暴的,但是没有成功,这就出现一个问题,
> 构建阵容的选择上,其实作为玩家可选择的东西感觉不够多。」

**这句话本身是好消息。** v1 的抱怨是「我不知道为什么我要选这个」,v3.2 的抱怨是
「我知道为什么选,而且能选得挺好,但选完就没了」,到这里变成了「我有自己想组的队,
可游戏不让我组」。玩家开始有构筑意图,是玩法往前走了一步之后才会出现的问题。

### 8.1 6 轮 1 跳撤回,改回 7 个市场日

七·2 那条收紧是在**旧发牌器**上得出的结论,新发牌器(按预算控价 + 缺位提权 +
后期保底)上从来没单独验证过。第一局就打出反例:

```
第 3 天(玩家放掉)  $4 步枪 EliGE(G5)  $1 狙 hypex  $4 步枪 NAF(G4)  $1 狙 meyern  $1 狙 peet
第 4 天            $1 狙 jambo  $1 指挥 TMB  $2 步枪 Liazz  $2 狙 ShahZaM  $3 狙 allu
```

他已经有 s1mple 和 HooXi 了,第四天五张里三个狙一个指挥。**这不是「选哪个步枪」,
是「只给了我这一个还能怎么办」。** 而他放掉的第三天恰恰是全局最好的步枪批——
EliGE $4 是 G5(抄底 +1 档),NAF $4 是 G4,穷举出来的最优阵容里就有 EliGE。

措辞也一起换了。原来 UI 写「还能跳 2 次」,听着像系统白送的刷新;现在写
**「7 个市场日 · 签 5 个人」**——你只是从七个交易日里完成五次签约,放掉一天是
你自己的取舍,不是消耗一张补给券。

### 8.2 发牌器现在知道你哪个位置已经满了

`need` 里只装「AWPER / IGL 缺不缺」。拿齐这两个之后,发牌器对位置就完全无感了——
你有了 s1mple,第五个狙出现的概率跟任何一个步枪一样。实测:

```
                        废位牌占板面    五张里 2 张以上是废位
拿齐 AWP+IGL(原)          35.6%              59%
加上位置配额降权(现)        19.7%              25%
```

「一批五张」实际上只有三张能选,这就是「可选择的不够多」的量化版本。
配额是 `{AWPER:1, IGL:1, RIFLER:3}`,超了的位置权重 ×0.45。**软降权不是禁**——
双狙、双指挥仍然摸得到,那是 `DOUBLE AWP` 这类标签能存在的前提。

### 8.3 蓝图 v0:把 aim 标签从赛后搬到赛中

第二局那 25 张牌里,**独联体人有 6 个**(dem0n 18 岁、npl 21 岁、fame 23 岁、
Kvem 24 岁、s1mple 28 岁、Zeus 38 岁),他也真拿到了三个,`UKRAINE CORE` 亮了。

**所以不是牌不给他。缺的是两样:他没法在还来得及的时候知道有没有料;以及组成了
也没有任何东西承认这件事。**

七·3 定的「标签只命名不算分」在这里露出了代价:标签只在赛后出现,等于一个事后
贴的名字,改变不了任何一次选择。所以这一版把 aim 标签从赛后搬到赛中——选人界面
常驻一行:

```
可以去追:  [DOUBLE AWP] 还差 1 个狙   [UKRAINE CORE] 还差 2 个 Ukraine 人
           [GALACTICOS] 还差 1 张 $5   [MONEYBALL] 接着只买 $1-2 的牌
```

**零新机制、不加分。** aim 标签本来就只用卡面看得见的东西(位置、国籍、标价)
判定,所以它天然就是一张「现在可以朝这走」的清单,这里只是把它挪到你还能行动的
时候,并算出还差几个人;已经不可能的(买过 $4 之后的 MONEYBALL)直接不显示。

为什么先做这个、不先做回报:**如果连「看得见」都不能让人产生想追的欲望,加分
也救不了它。** 这是一次很便宜的试探。

评审提过的 **SCOUTING FOCUS**(整局限一次,按下之后下一批把「同国 / 年轻 /
老队友 / 缺的位置」权重 ×2,提高概率而不保证出现)是个好设计,但它和蓝图不是
一回事:**FOCUS 是方向盘,蓝图是目的地。**

- 只做 FOCUS:第二局会变成——花掉唯一那次 focus 搜年轻人,真的凑出青春风暴,
  然后 Reveal 告诉他同国籍 +1.5×2 = +3,为此少了两档火力,总分更低。
  **方向盘转到了一个不值得去的地方。**
- 只做蓝图:就是今天的第二局,脑子里有目的地,发牌器不知道。

顺序上先做便宜的那一半,看它能不能让人产生意图;有意图了再谈回报,有回报了
FOCUS 才有意义。

### 8.4 「更该拿 X」改成「事后最优」

第一局玩家组的是 HooXi + s1mple + Liazz + b1t + HeavyGod,379/17826(前 2%),
他自己觉得这队挺好。然后复盘丢给他一句「HeavyGod 选错了,更该拿 $1 Vexite,
差 4.2」。他的原话是「我没有看懂」。

把那 4.2 拆开:

```
默契  +3.5   ← Vexite 是澳洲人,和 Liazz 同国籍
余钱  +0.6   ← 便宜 $1,多 1 点 Rogue Point(而且那还是测试桩)
卡本身 +0.1
```

**九成是同国籍默契,而那正是他自己在做的事**(他以为自己组了三个乌克兰人)。
同一局第三天的建议 `$1 AWPER jambo` 也一样——jambo 是乌克兰人。
面板只给一个名字和一个数字,于是一条「你做对了方向,只是选错了人」读起来像
「你不会玩」。

两个修:

1. **说出理由**:`事后最优 $1 Vexite / 默契 +3.5 多了「同国籍 Australia +1.5」·
   余钱 +0.6`。默契变好可能是多了一条加分,也可能是**少了**一条罚分(不再是三个
   指挥抢话),两种说法分开写。
2. **改措辞**:「逐轮后悔 / 更该拿」→「**事后最优**」,并在标题下写明这是上帝视角:
   用的是揭晓后的完整真值(精确四维、组合出来的默契、省下的 Rogue Point),
   全都是当时看不到的。**在信息不全时做判断本来就是这个玩法的核心**,拿全知
   结果去宣判当时的选择,等于把它拖回「做题」。

### 8.5 「你错过了谁」:每个市场日全部翻开

结算里现在会把七批 35 张牌全部翻开:当时卡面上写的是什么 → 他实际上是谁 →
真实档位和四维,并标出 `你签下` / `错过的抄底` / `标价虚高`。

这一条是同一局实测里另一个抱怨带出来的:**「感觉某些选手的出场率好高」——
不是错觉。** 4000 局统计:

```
档位   库里人数   占卡池   占板面
G5      34 人     5.2%    10.5%
G4      35 人     5.4%    15.3%
G1     309 人    47.7%    26.3%

G4 + G5 一共 69 人(占卡池 10.6%),占了板面的 25.8%
```

再切细一点,**「一个买得起的好狙」这个位子全库只有 12 个人能坐**(G5 狙 7 人 +
G4 狙 5 人),G4 指挥只有 7 人、平均出场率 12.8%。所以玩家记住的不是「s1mple 常
出现」,是每次出现一个买得起的好狙,它就是那十几个人之一,而那十几个恰好全是
他认得的。

```
NAF 12.2%   EliGE 8.4%   dev1ce 7.6%   ZywOo 6.6%   s1mple 6.5%   m0NESY 6.5%
中位数选手 3.08%    最冷的 10% 约 0.35%    最热是最冷的 40 倍
```

**而全板揭晓正好是这件事的解药,不是补丁。** 现在这 69 张脸每局反复出现,但玩家
从来不知道没买的那些是谁,所以重复只是噪音;翻开之后,「上次就是这哥把我坑了」
会变成下一局的记忆。他之前抱怨的「老哥太多、大部分人都不认识」,最自然的解法
不是给百科教程,是每局结束时对一次答案。**重复出现是学习曲线的前提。**

留一个待查:`GRADE_WEIGHT` 里 **G4 = 2.2 比 G5 = 1.5 还高**,第二梯队比第一梯队
更常见,出场率前 18 名里 17 个是 G4(而且全是现役在队的,因为自由身/大龄降权把
退役传奇压下去了)。这个权重当初是为了「$15 花得掉」调的,但 G4 > G5 这个顺序
看着像手滑,下一版重扫。

### 8.6 标签底下显示默契里已经算过的那笔

`REUNION` 下面显示 `队友 s1mple + b1t 同队 N 届 Major(navi) +2.0`。

### 8.8 v3.4 第一次实测:蓝图没有制造意图,但制造了取舍

两局,第二局(seed 307338766)玩家自己的评价是「玩的很刺激……我认为现在这个版本
就还可以了」。最终 $4 gla1ve(G5)+ $4 stavn(G4)+ $3 YEKINDAR(G4)+

这一局可以逐天复算(它是在 v3.4 上打的),所以下面每条都对得上牌面。

**1)意图来自认人,不是来自蓝图面板。** 他的原话是「第一天一眼看到 4 块钱的王朝
指挥 gla1ve,马上就感觉到可以组老 A 队了」。那张卡面是
`$4 指挥 · 领导 86–99 · Denmark · 100 Thieves`——他是靠认出人产生的构筑意图,
蓝图面板当时还只是一行通用清单。**所以蓝图 v0 没有"制造"意图。**

**2)但它把意图变成了取舍。** 第四天出现 `$3 指挥 · 火力 46–58 · Denmark ·
Major x8`(cadiaN),而面板上同时亮着 `[DENMARK CORE] 还差 1 个 Denmark 人` 和

的那个矛盾。原型当初就是为了捕捉这个信号才做的(见第一节)。

七·3 定的「只命名不算分」到这里拿到了正面证据:不加分也能改变玩家怎么看待自己

**5)一个讽刺:HeavyGod 的 Israel 这次帮了他。** 第六天
`$1 步枪 · 稳定 55–69 · Israel · Major x4`,他说「4 次 major 的以色列步枪那肯定

## 九、Reveal 还该往哪走

原型页面现在很简陋,但结算这一层是「选完之后发生什么」唯一已经存在的部分,
所以先把方向记下来。

**现在有的**:总分 + 穷举名次、四块计分牌(选牌准度 / 预算管理 / 阵容契合 /
最大抄底)、阵容标签、默契明细、事后最优、全板揭晓。

**下一步该做的,按我认为的优先级:**

1. **分段揭晓,别一次倒完。** 现在分数摆在最上面,等于先剧透结局。应该先翻
   「你签的这五个人是谁」(情绪最高点),再给这是支什么队,再给分数,最后才是
   错过了谁。顺序本身就是叙事。
2. **抄底要是一个事件,不是表格里的一行。** `$2 买到 G4` 值得一个单独的高亮时刻。
   现在它被压在一列标签里,玩家甚至没注意到自己一局抄到过三张(见七·1)。
3. **比赛结果才是真正的 Reveal。** 目前的「总分 + 第几名 / 共几套」是占位符:
   它回答的是「这批牌你选得好不好」,不是「这支队怎么样」。等极简 Run 做出来,
   揭晓应该是这支队打出了什么成绩,四维在比赛里被消费,而不是加权求和。
   这也是第七节末尾那个「更上层的问题」的落点。
4. **全板揭晓天然是图鉴入口。** 这一局第一次见到的人应该标成「新面孔」并累计。
   口径按之前定的,从「我认识多少人」改成「我抄到过多少底」。
5. **标签要有画面。** 现在是一个英文 tag 加一行中文说明。真正该有的是队名感、
   一句话战报——「三个乌克兰人和一个丹麦指挥」比 `UKRAINE CORE` 有画面得多。
6. **要能分享。** 一张卡片式战报(五个人 + 标签 + 一个数字),这才是会被发出去
   的东西,也是这个项目做图鉴/社区的真正入口。
7. **警惕把它做成做题。** 「事后最优」这一栏本身有风险:如果玩家开始为了把差值
   刷到 0 而玩,这个游戏就回到了「猜正确答案」,而那正是 v1 被推翻的地方。
   考虑默认折叠,或者干脆只在玩家主动点开时才算。

## 附录 B:怎么复算

上面每一组数字都可以重跑。命令行版直接玩:

```
.\.venv\Scripts\python -X utf8 scripts\proto_draft.py            # 盲选
.\.venv\Scripts\python -X utf8 scripts\proto_draft.py --open     # 明牌对照
.\.venv\Scripts\python -X utf8 scripts\proto_draft.py --seed 7   # 复现同一局
.\.venv\Scripts\python -X utf8 scripts\export_draft_web.py       # 重新生成网页版
```

**web 版的对局可以在 Python 里逐分重放**:它用的是 mulberry32,在 Python 里用
`u32/i32/imul` 复刻同一个整数序列,再按同样的顺序(`TIERS = [5,4,3,2,1]`,
每档带权洗牌、从尾部取)发牌即可,`proto_draft.Dealer` 之外的部分完全共用。
分析脚本没有入库(一次性的),但复刻只有二十行,重写比维护便宜。
