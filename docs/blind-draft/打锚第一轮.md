> 2026-09-02。VRS 前 15 队、75 个首发,人工打了 **31 个火力锚**(29 个枪手 + 2 个指挥)。
>
> 起因是一句自我怀疑:「越打越觉得分数不够客观,top 哥和观感好的人在我这里
> 加分太多了」。**这个怀疑经不起数据检验**——下面每一条可测的偏见假设都测了,
> 全部不成立。真正的发现在别处。

## 二、你打出来的尺子

29 个枪手锚拟合出的二次曲线:

```
rating 1.00 → 火力 67.5      1.21 → 87.3
       1.05 → 73.4           1.30 → 92.0
       1.10 → 78.5           1.41 → 94.6
       1.15 → 82.9           1.44 → 94.7
```

形状是 **S 型:中段最陡、顶端饱和**。1.00→1.10 每 0.1 涨 11 点,而
1.41→1.44 几乎不动了。这和讨论时那句「donk ZywOo 是论外的」完全一致——
**顶端是一个会饱和的区域**,再高的 rating 也换不来更多火力,因为 96 已经贴着
你自己留的余量上限(「单局比赛中也可能出现 2+ 的超高 rating」)。

## 三、两个偏见假设,都测了,都不成立

### 3.1 「top 哥加分太多」

拿 HLTV Top20 履历当"top 哥"的操作化定义,比较残差:

```
有 Top20 履历(13 人)   残差中位 +1.19   均值 +0.40
没有      (16 人)      残差中位 +1.00   均值 -0.32
```

**中位数差 0.19 点。** 在残差 σ = 2.4 的尺度上,这是零。

更直接的反证:**残差最负的两个人恰恰是履历最厚的两个**——

```
donk    Top20 第 1 名 ×2   残差 -3.7
ZywOo   Top20 第 1 名 ×7   残差 -3.9
```

而残差最正的那批里,kyousuke、PR、HUASOPEEK **一次 Top20 都没有**。

### 3.2 「按将来的期望给分」

备注里带将来时的(「今年应该能拿 top」「年轻潜力股」「也许没到巅峰」)共 5 人:

```
这 5 人残差均值 +0.35     其余 24 人 -0.07
```

也是零。只有 PR 一个人是真正的外点(+4.5),其余四个里 HeavyGod 还是 −2.6。

### 3.3 那种"加分感"到底是什么 —— **是曲率**

用直线去拟合,残差按 rating 分段:

```
rating ≤ 1.10     残差均值 -2.04
       1.11–1.29  残差均值 +1.38
       ≥ 1.30     残差均值 -2.83
```

**两端负、中间正**,标准的 S 型信号。你给中段的人「多加了分」,只是因为
拿直线量一条曲线,中段必然显得偏高。换成二次,R² 从 0.838 升到 0.922,
残差 σ 从 2.67 降到 1.85——**那种不适感的大部分是模型的错,不是你的**。

## 五、`peak` 那个勾没起作用 —— 口径因此定成「当前尺」

勾「否」的六个人,本该按**生涯巅峰**给分。实际填出来:

| | 当前 rating | 你打 | 离「当前 rating 建议值」 | 离卡面生涯值 |
|---|---|---|---|---|
| NiKo | 1.18 | 84 | **+0** | −9 |
| KSCERATO | 1.23 | 87 | **+0** | +4 |
| ropz | 1.19 | 86 | +1 | −5 |
| YEKINDAR | 1.15 | 83 | +1 | +0 |
| TeSeS | 1.05 | 77 | +1 | +10 |
| mezii | 1.10 | 76 | −3 | +8 |

**离当前值平均 1.0 点,离卡面 6.0 点。** 勾了「否」,填的还是他现在的数。

最清楚的是 NiKo:卡面 93,你给 84,正好等于当前 1.18 推出来的值;
备注是「年纪大了,也不在巅峰,但是数值合理」——**这句话本身就是在按当前给分**。

**这不是填错,是这一页本来就更适合回答"现在"。** 证据全在当前这一侧。
所以口径定下来:

> **这 31 个锚定义的是「当前能力」的尺子。生涯值另开一轮,
> 用荣誉 / Top20 / 同时代地位往这把尺上映射。**

`peak` 字段保留,但含义收窄成「他的当前 rating 能不能代表他的上限」——
用来标记 ax1le 那种伤病远离一线的人,而不是用来切换两把尺子。

## 六、MVP/EVP:抓不到,而 Top20 顶不上它的位

备注里反复出现三个 rating 装不下的变量:

```
"top 哥基本都有 mvp evp"          → 大赛荣誉
"王朝突破手…资源太少"              → 队内资源占比
"经典的辅助奉献位置,没有资源"       →
"经典几个赛事爆发 life game"       → 爆发型 vs 稳定型
```

MVP/EVP 拿不到(老选手更拿不到),所以想用 HLTV Top20 顶替。
**§3.1 已经证明它顶不上**——Top20 对残差的解释力是零。

这不意味着 Top20 没用,而是**它和 MVP/EVP 回答的不是同一个问题**:
Top20 是年度总评(生涯侧的量),MVP/EVP 是单赛事的决定性表现(当前侧的量)。
拿年度榜去解释单场爆发,本来就对不上。

**Top20 的位置在生涯那一轮**(第五节说的映射),不在当前尺这一轮。

至于"队内资源占比",这个**是能算的**:5E 有 kpr 和首杀数,
资源占比 ≈ 个人回合参与度 / 全队。要不要加成一列,没定。
