## 一、问题:档内火力现在基本是掷骰子

同档内「卡上火力」和「近 12 个月实测 rating」的秩相关:

| 档 | n | ρ |
|---|---|---|
| G5 | 16 | **0.635** |
| G4 | 17 | 0.162 |
| G3 | 34 | 0.135 |
| G2 | 59 | 0.142 |
| G1 | 100 | 0.223 |

G5 之外全是噪声水平。原因不是公式差,是**没有输入**:

| 档 | 卡数 | 有 Top20 履历 | 有 5E 实测 |
|---|---|---|---|
| G5 | 34 | 94% | 56% |
| G4 | 35 | 89% | 60% |
| G3 | 87 | 41% | 46% |
| G2 | 183 | **0%** | 47% |
| G1 | 309 | **0%** | 41% |

**G2+G1 是 492 张卡、全库的 76%,Top20 覆盖率是零。** `corrections()` 里
火力那一项写的是 `if entries:`——对这 492 个人整段不执行。他们的火力 =
模板底板 + 年轻人 +2.5 + 抖动。所谓「同档拉不开」不是幅度不够,
是那 6 点档内空间里**没装任何信息**。

而 5E 实测覆盖了这两档的 41–47%(G1 有 127 人、G2 有 86 人),
rating 跨度分别是 0.93 和 0.52。信息一直在,只是没接上。

## 三、已定的口径

| | 定了什么 | 为什么 |
|---|---|---|
| **grade** | **不动** | 见第七节第 3 条,这件事本身还没想清楚 |
| **experience** | **不动** | 只跟荣誉和场次走 |
| **stability** | **不从 kast 推** | 见下 |
| **firepower** | **接实测** | 本文其余部分 |

### stability 为什么不接 kast

stability 的定义是:**样本足够时,选手所有场次 rating 的方差**——越稳,
每张图打出来的数越接近。**这个数我们没有**,5E 只给聚合值,不给逐图。

KAST 不是它的代餐:实测 `stability ~ kast` 只有 0.22–0.44,而且随图数漂。
拿一个相关 0.3 的量去驱动一维,等于给这一维换个更随机的来源。

引擎里这一维已经是这个语义了(`match.py:151`):

```python
sigma = (100 - c["stability"]) / 4.0      # 单图火力的波动幅度
```

所以它只能当**先验**用(没证明过的年轻人打得飘),不能当**测量**用。

### experience 为什么不能拿来当补偿

讨论里出现过「用降 experience/stability 来补偿火力上涨」。experience
这条走不通,两个理由:

1. **没有空间。** G1 模板经验就是 20,这批要涨火力的人现在 21–24,
   贴着地板。
2. **会记两遍。** experience 这一维**本来就在说「履历薄」**。再扣一次,
   等于同一个事实扣两次分。

所以补偿只能从 stability 出。这不是找个数凑平衡——给一个没打过 Major 的
年轻人扣稳定,说的正是「他能打出这个数,但你不知道他哪天打不出来」,
和引擎里 sigma 的语义一致。

## 四、映射怎么做:**分位对齐是错的**

这是今天最值钱的一条,而且第一版就是这么写的、跑出来才发现不对。

### 第一版:分位对齐(已废弃)

把「现役 rating 的百分位」映到「同一批人卡面火力的百分位」。
听起来自校准、不用手挑锚点、还保证分布不膨胀。跑出来是这样:

| rating | 分位 | 火力 |
|---|---|---|
| 1.00 | P35 | 55 |
| 1.05 | P55 | 60 |
| 1.10 | P74 | **69** |
| 1.15 | P88 | **81** |
| 1.18 | P93 | **90** |
| 1.25 | P99 | 94 |
| 1.30 | P99 | 94 |
| 1.44 | P100 | 96 |

**中段陡得离谱、顶端挤成一坨。** rating 从 1.10 到 1.18 只差 0.08,
火力要跨 21 点;而 donk 的 1.44 和别人的 1.25 都落在 94–96。
方向正好反了——**顶端才是样本最足、差异最可信的地方,曲线偏偏在那里压平**。

### 为什么必然会这样

同一批 226 人身上,两个量的离散度根本不是一回事:

```
rating   : 中位 1.04   标准差 0.126   10–90 分位 0.91 .. 1.16
卡面火力 : 中位 59     标准差 12.1    10–90 分位 51 .. 83
```

rating 在「世界前 45 支队的首发」这个人群里**被选择压窄了**——能坐上
这些位置的人本来就都不差。而卡面火力量的是**生涯**,同样这批人里有
传奇也有无名之辈,自然铺满全程。

分位对齐 = 强行把窄的摊成宽的,所以中段必然陡、两端必然平。

### 第二版:回归

在样本足的人身上(≥80 图、S 级实测,n=65)拟合:

```
火力 = -18.0 + 79.4 × rating        R² = 0.326   残差 σ = 10.0
```

| rating | 分位对齐 | 回归 |
|---|---|---|
| 0.90 | 51 | 53 |
| 1.00 | 55 | 61 |
| 1.10 | 67 | 69 |
| 1.15 | 80 | **73** |
| 1.20 | 91 | **77** |
| 1.30 | 94 | **85** |
| 1.44 | 96 | 96 |

rating 每高 0.10,火力高约 **7.9** 点。单调、无断崖、顶端不压缩——
donk(1.44)、ZywOo(1.41)、m0NESY(1.33) 之间的差距被保住了。

### 教训

> **预测器不完美时,预测值就应该比真值更挤。**

分位对齐保留离散度,回归压缩离散度。R² = 0.326 意味着 rating 只解释了
火力三分之一的方差——这时候把 rating 的排序原样铺开成火力的排序,
就是把 67% 的噪声当信号放大。**分位对齐只在预测器完美(ρ=1)时才是对的。**

## 五、收缩:k ≈ 31 图

按图数分桶拟合 `var(n) = σ²_t + σ²_e/n`:

```
σ_t = 0.080(真实差异)   σ²_e = 0.198(单图噪声)   k = σ²_e/σ²_t ≈ 31 图
权重 w = n/(n+31):  13 图→0.30   51 图→0.62   160 图→0.84   214 图→0.87
```

*(诚实标注:140–200 那个桶的方差反常偏高,拟合不干净。k 的**量级**可信,
具体数值别当定论。)*

**这条也解释了一个看起来像 bug 的现象。** 第一版结果里
「1.19 → 88 而 1.18 → 76」看着像断崖,其实不是曲线的事:

| | rating | 图 | w | 纯数据值 | 收缩后 |
|---|---|---|---|---|---|
| molodoy | 1.19 | 207 | 0.87 | 90 | **88** |
| luchov | 1.18 | **51** | 0.62 | 90 | **76** |

两人纯数据值都是 90。luchov 掉到 76 是因为**只有 51 图**,收缩把他拉回了
模板。这是收缩在正常工作,不是曲线坏了——但它确实说明**结果表要连图数
一起看**,只列 rating 会误导。

## 六、IGL:数据说 rating 对指挥没有信号

讨论里提过「IGL 火力本来就可以很低,而且 IGL 的评分里火力只占 0.25」。
前半句对,但**这不是要不要让 rating 驱动 IGL 火力的理由**。决定性的数是这个:

| 图数下限 | 枪手 ρ (n) | IGL ρ (n) |
|---|---|---|
| 不限 | 0.411 (226) | 0.209 (67) |
| ≥20 | 0.428 (182) | 0.159 (52) |
| ≥50 | 0.456 (136) | 0.179 (42) |
| ≥80 | **0.599** (104) | 0.148 (32) |
| ≥120 | **0.674** (85) | 0.224 (29) |

**枪手随样本单调上升 0.41 → 0.67;IGL 在 0.15–0.22 之间原地不动。**
关键不是「IGL 更低」,是**它不随样本增长**——信号真实存在时,加样本会把它
从噪声里显出来,枪手那一列就是这个过程。IGL 这一列没有这个过程。
(诚实标注:IGL 那列在 ≥120 时回到 0.224,不是单调下降;n 也只剩 29。
能说的只有「没有随样本上升」,不能说「越多越低」。)

具体看也是同一件事:

```
karrigan  G5 火力66  rating 0.83(168 图)   纯叫战术的指挥
blameF    G4 火力62  rating 1.19( 36 图)   自己也开枪的指挥
```

两个人都是**正确的 IGL**,rating 分不出他们在生涯卡上该差多少火力,
它只反映了这支队怎么分配资源。原样跑的结果是 karrigan **66 → 47**,
低于 G1 指挥的模板底板(45)——模型等于在说「世界上最好的叫位者,
枪法比一个三线队的无名指挥还差」。

**这一条是测量结论,不是口味。** 要不要仍然让 IGL 进通道是第七节的开放项,
但如果进,得知道进的是噪声。

## 七、还没定的三件事

### 1. 曲线怎么定标

回归版跑完枪手火力中位 **59 → 65**,平均 **+5.2**——有系统性上移。
两个来源:(a)「有 Top20 只升不降」的护栏本身是单向的;
(b) 回归是在 ≥80 图那批人身上拟合的,那批人比全体强。

要不要把整条线重新居中(比如让改动的中位数为 0),没定。

### 2. IGL 进不进通道

- **不进**(实验里的选择):karrigan 保持 66。理由见第六节。
- **进**:能接受 karrigan → 47。理由是 IGL 权重只有 0.25,overall
  只掉 4.75;而且 AI 卡那边还有大龄下滑机制在同时压他。

第六节的数据支持「不进」,但代价确实有限,所以这是个可以选的事。

### 3. grade 升不升 —— 以及 tier_gap 会坏

**这是三件里最难的一件。**

目前定的是 grade 不动。但那样会撞上 `draft.py:524`:

```python
def tier_gap(c):
    return c["grade"] - c["price"]      # 驱动 BARGAIN BIN 和「最大抄底」
```

**它假设 grade 就等于实力。** 解耦之后不成立:一个 $1 买到的 G1、
火力 78 的人,按这个式子 `tier_gap = 0`——**游戏会告诉玩家这不是抄底**,
而它恰恰是全场最大的抄底。想要的捡漏玩法正好被这一行挡住。

而如果反过来让 grade 跟着实测升,又有一层公平问题:

> 年轻人用的是新尺子(5E 近 12 个月),退役和过巅峰的人用的是老尺子
> (Top20 + Major)。**只给一边换尺子,升的那批就是白捡的。**

两条出路:

- **改 tier_gap,不动 grade。** 抄底改成按能力(四维/overall)算,
  grade 退回它本来的意思:生涯证据等级。改动小,但要重新想球探提示
  怎么在不剧透四维的前提下暗示「这人枪很硬」。
- **等历史数据,再统一换尺子。** 见下一节。

## 八、能解开死结的那件事:5E 的逐年历史数据

5E 能查 2016–2026 的分年数据。如果把历史抓下来,第七节第 3 条的公平问题
**直接消失**:

```
s1mple 2018  ←→ 和 2018 年的 S 级选手比
donk   2024  ←→ 和 2024 年的 S 级选手比
```

每个人都在**自己的巅峰年份、和同年代的人**比,同一把尺子。那时候才谈得上
问「electroNic 最好的那年到底该是 F91 还是 F87」。2013–2015 没数据,
老生成器继续兜底,不影响系统运行。

在那之前,「只给年轻人升 grade」都是拿两把尺子量两批人。
